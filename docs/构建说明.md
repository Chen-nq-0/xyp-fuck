# 模块源码与构建说明（v17）

## 目录结构
```
源码/
├── AndroidManifest.xml          # 模块清单（package io.dsh.campusrun, xposedmodule）
├── assets/xposed_init          # 入口：io.dsh.campusrun.AdBlockModule
├── build.sh                    # 构建脚本（aapt2 → javac → d8 → zipalign → apksigner）
├── api-82.jar                  # Xposed API 82（编译用）
├── res/                        # 图标与 arrays.xml（模块描述）
└── src/io/dsh/campusrun/
    ├── AdBlockModule.java      # 模块入口 + 主逻辑
    ├── AdGate.java             # 广告中台总开关（canLoad*/init/load* 等门）
    ├── AdRecon.java            # 逆向调试：枚举广告类/方法签名（非运行必需）
    ├── DexDumper.java          # 逆向调试：原生内存 dump 驱动（非运行必需）
    └── ProbeModule.java        # 早期探针模块（非运行必需）
```

## 构建依赖
- JDK 8 或以上（脚本用 `-source 8 -target 8`）
- Android SDK：platform **android-35**、build-tools **37.0.0**
- 签名密钥：脚本默认 `/home/USER/android-re/re-keys/release.jks`（别名 `re`，口令 `android`），可换成自己的

## 构建步骤
1. 修改 `build.sh` 顶部 4 个路径（SDK / build-tools / keystore / 工作目录）为本机路径
2. 执行 `bash build.sh`
3. 产物：`build/module-probe.apk`（安装到手机即可，LSPosed 中启用并勾选「运动世界校园」作用域）
4. **每次更新模块后必须强制停止目标 App**，否则旧代码仍在运行

## 关于「App 源码」
目标 App 使用网易易盾整体加固 + 类抽取（classes.dex 71MB 中只有 30 个壳类，方法体不在文件里），**不存在可直接反编译得到的业务 Java 源码**。本模块的拦截点来自运行时逆向：
- `dec/`：apktool 解包结果（资源、AndroidManifest、壳 smali）
- `jadx-out/`：jadx 反编译（仅壳代码）
- `recon.txt`：运行时反射枚举出的广告中台类与方法签名
- `advertise-classes.txt`：从壳 dex 字符串池恢复的 6732 个 App 类名中的广告相关子集

原始 APK 与上述逆向产物仍在 WSL：`/home/USER/android-re/work/base1/`（base1.apk 330MB、dec/、jadx-out/、dump-app/、analysis/）。
