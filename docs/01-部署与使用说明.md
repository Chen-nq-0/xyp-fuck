# 运动世界校园 v7.3.93 · 去广告部署与使用说明

规则文件都在同目录的 `rules/` 下。三条路选一条即可，**都不用改 APK、不用重签名**。

---

## 先选方案

| 你的环境 | 推荐方案 | 作用范围 | 误伤风险 |
|---|---|---|---|
| 手机装了 **AdGuard for Android**（推荐） | 方案 A：按应用过滤 + 完整版规则 | 只对「运动世界」生效 | 无 |
| 路由器跑了 **AdGuard Home** | 方案 B：自定义过滤规则 | 全网络 | 用安全版即可，完整版会误伤淘宝/抖音 |
| 路由器/电脑跑了 **OpenClash / Clash** | 方案 C：rule-provider | 走代理的设备 | 用安全版 |
| 手机已 root（Magisk） | 方案 D：hosts | 全局 | 用安全版 |

> 核心原则：**完整版只在「按 App 生效」的场合用；全局生效一律用安全版。**

---

## 方案 A：AdGuard for Android（按应用过滤，最推荐）

1. 安装 [AdGuard for Android](https://adguard.com/zh_cn/adguard-android/overview.html)（本地 VPN 模式，不需要 root）；
2. 打开 AdGuard → **设置 → 网络 → 路由/应用过滤**：
   - 「过滤模式」选 **仅过滤选中的应用**（或「过滤应用」里只勾选「运动世界」）；
3. 打开 **设置 → 过滤器 → 自定义过滤器 → 添加自定义过滤器**，把
   `rules/campusrun-adguard-full.txt` 的**全部内容**粘进去（或直接用「导入」）；
4. 打开 AdGuard 主开关，启动「运动世界」，广告应消失。

因为只对这一个 App 生效，所以可以用**完整版 128 条**，不会影响淘宝、抖音等其它 App。

---

## 方案 B：AdGuard Home（路由器 / 小主机）

1. 登录 AdGuard Home 后台 → **过滤器 → DNS 黑名单（自定义规则）**；
2. 「添加过滤器」→ 自定义列表，把 `rules/campusrun-adguard-safe.txt` 的内容粘贴进去并保存；
3. 手机 DNS 指向 AdGuard Home，清一下手机 DNS 缓存（开飞行模式再关，或重启 Wi-Fi）；
4. 验证：AdGuard Home 的**查询日志**里应能看到这些域名被拦截。

> 如果需要**只对这台手机生效**，可以在 AdGuard Home 的「客户端」里按手机 IP 单独配置过滤器，
> 这样完整版也能用，不会影响家里其它设备。

---

## 方案 C：Clash / OpenClash（rule-provider）

把 `rules/campusrun-clash-safe.yaml` 放到 Clash 配置目录的 `ruleset/` 下，
在 `config.yaml` 里加：

```yaml
rule-providers:
  campusrun:
    type: file
    behavior: domain
    format: yaml
    path: ./ruleset/campusrun-clash-safe.yaml

rules:
  - 'RULE-SET,campusrun,REJECT'
  - 'MATCH,你的默认策略'
```

**必须放在 ``rules`` 列表最上面**，Clash 是按顺序匹配的。
也可以改用在线订阅（GitHub 源或 jsDelivr 镜像），但本目录的版本已核对 7.3.93。

---

## 方案 D：hosts（需要 root）

把 `rules/campusrun-hosts-safe.txt` 的内容追加到 `/system/etc/hosts`
（或做成 Magisk 模块）。改完执行：

```bash
su -c 'settings put global private_dns_mode off'   # 如果有开私人 DNS，先关掉
su -c 'ip link set wlan0 down && ip link set wlan0 up'
```

hosts 是**全网络生效**，请务必用安全版。

## 验证方法

1. **看广告页**：打开 App，开屏广告、首页弹窗、信息流广告应不再出现（可能有空白位）。
2. **看拦截日志**：
   - AdGuard：主界面「统计」里能看到 `gdt.qq.com`、`sdk.e.qq.com`、`pangolin-sdk-toutiao.com` 等被拦；
   - AdGuard Home：查询日志里对应域名显示「已拦截」；
   - Clash：Connections 里对应域名显示 `REJECT`。
3. **确认业务正常**：登录、跑步、打卡、成绩查询、定位都要正常 —— 业务域名（`*.gxapp.iydsj.com`、
   高德 `*.amap.com`）不在规则里，理论上不受影响。

## 常见问题

**Q：拦了之后广告位置变成一块空白，能彻底去掉吗？**
A：域名拦截只能让广告请求失败，广告容器通常还在。想连空位一起去掉，需要改 App 代码
（LSPosed 模块 / 脱壳改包），见分析报告第 9 节。

**Q：为什么完整版会误伤别的 App？**
A：完整版包含 `taobao.com`、`alicdn.com`、`pstatp.com` 这类大厂主域/公共 CDN，
其它 App 正常加载图片、登录也会用到。所以完整版只适合「按 App 生效」的场景。

**Q：用了安全版还有少量广告？**
A：把被拦住后仍在的广告域名发我（或用 App 内的抓包/AdGuard 日志），我可以补进规则；
也可以临时切完整版观察是哪个域名漏了。

**Q：会封号吗？**
A：域名拦截只作用于广告 SDK，不改 App 数据、不伪造跑步，属于客户端过滤，风险极低；
但任何第三方修改都有被平台检测的可能，自行权衡。

## 复现分析用到的命令

```bash
# 1. 结构
aapt2 dump badging base1.apk | head
apkid base1.apk

# 2. 确认加固
apktool d -f base1.apk -o dec          # 只解出 30 个壳 smali
unzip -p base1.apk classes.dex > c.dex
dexdump -f c.dex | grep -E 'class_defs|method_ids'   # 30 / 656

# 3. 广告 SDK 证据
grep -oE 'android:name="[^"]+"' dec/AndroidManifest.xml | grep -iE 'kwad|pangle|gdt|mobads|tianmu|yfan|adgain|jd\.ad|mimo'
cat dec/res/xml/network_security_config.xml

# 4. 规则生成（本目录 rules/ 里的文件）
python3 gen_rules.py
```
